# Запуск и проверка для жюри

Нужны Docker с Compose v2 и интернет. Запуск использует CPU; отдельные ключи нейросети и поиска не требуются.

## Запуск

1. Клонируйте репозиторий. Поместите переданный командой заполненный `.env` рядом с `compose.yaml`, заменив шаблон. Если используете своего бота, выполните `python3 scripts/init_env.py` и укажите `MAX_BOT_TOKEN` в `.env`.
2. Остановите другие экземпляры с этим токеном. Для polling у бота не должно быть активного webhook.
3. Выполните:

   ```bash
   docker compose --profile polling up -d --build
   docker compose --profile polling ps -a
   ```

4. Дождитесь `model-init: Exited (0)` и работающих `worker` и `polling`. Первая загрузка модели — около 6,6 ГБ.
5. Откройте в MAX **@t439_hakaton_max_bot**. Если используете свой токен, откройте соответствующего бота.

В `.env` используются `MAX_BOT_TOKEN` и `POSTGRES_PASSWORD`; остальные настройки уже подготовлены. `ADMIN_TOKEN` нужен только для админки. `BOT_DOMAIN`, `MAX_WEBHOOK_URL` и `MAX_WEBHOOK_SECRET` нужны только для webhook.

## Основной сценарий

Каждое сообщение отправляйте отдельно, дожидаясь ответа.

1. `/start` → `/consent` → «Подготовиться к регистрации».
2. Опишите бизнес, например «Фотосъёмка мероприятий», и подтвердите предложенный ОКВЭД.
3. Ответьте на вопросы: предпочтение по налогам, регион, годовой доход, расходы, сотрудники и клиенты. Можно попросить помочь с выбором режима.
4. Посмотрите сравнение и подтвердите выбранный режим.
5. Укажите гражданство, возраст и способ подачи. Запросите `/checklist`, `/pdf`, `/steps`.
6. Отправьте `/profile`: бот должен показать введённые данные. Задайте вопрос `/ask Какие документы мне нужны для регистрации ИП?`.
7. Отправьте «Привет, как дела?»: бот отвечает без поиска документов. Вернитесь к сохранённому шагу через `/continue`.

Общего ограничения времени ответа нет; скорость поиска и генерации зависит от ресурсов и доступности источников.

## Управление

```bash
# Логи
docker compose logs -f worker polling
# Остановка, данные сохраняются
docker compose --profile polling down
```

Не добавляйте `--volumes` при остановке, если нужно сохранить базу и скачанную модель. Заполненный `.env` передаётся отдельно и не должен попадать в публичный коммит.
